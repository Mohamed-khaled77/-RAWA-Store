# لمسة (Lamsa) — متجر إكسسوارات وميك أب

> **لو عندك `.env` من قبل (من مرحلة سابقة):** شغّل `./setup.sh` تاني بنفس الباسورد، هو هيعمل الملف من جديد بكل المتغيرات المطلوبة للحسابات (NEXTAUTH_SECRET).

## المرحلة الحالية
- ✅ هيكل المشروع (Next.js 15 + TypeScript + Tailwind)
- ✅ الصفحة الرئيسية كاملة (Header, Hero, الأقسام, المنتجات مع فلترة, بانر, Footer)
- ✅ الصفحة متربطة بقاعدة بيانات حقيقية عبر Prisma
- ✅ السلة (إضافة، حذف، تعديل الكمية)
- ✅ حسابات حقيقية للعملاء (تسجيل + دخول) وصفحة إتمام طلب مربوطة بالحساب
- ✅ داش بورد للإدارة: إضافة/تعديل/حذف منتجات، ومتابعة الطلبات وتغيير حالتها
- ⏳ الخطوة الجاية: النشر على الإنترنت بدومين حقيقي

## بيانات دخول الأدمن (بعد ما تشغّل `npm run db:seed`)
- رقم الموبايل: `01000000000`
- كلمة السر: `admin123456`

⚠️ **مهم:** غيّر الباسورد ده بعد أول تسجيل دخول، أو اعمل حساب أدمن جديد بباسورد تاني
وامسح ده من `npx prisma studio` (غيّر دور أي حساب لـ ADMIN من عمود `role`).

## إزاي تدخل الداش بورد
1. سجّل دخول من `/login` ببيانات الأدمن اللي فوق
2. هتلاقي زرار "الداش بورد" ظاهر جنب أيقونة الحساب في الهيدر
3. أو روح على `/dashboard` مباشرة

## إعداد قاعدة البيانات (Supabase) — خطوة بخطوة

### 1. اعمل مشروع على Supabase
- روح على supabase.com واعمل حساب مجاني
- اضغط "New Project"، اختار اسم وباسورد لقاعدة البيانات (احفظ الباسورد كويس)

### 2. هات رابط الاتصال
- من داخل المشروع: Project Settings > Database > Connection String
- اختار "URI" وانسخه (هيكون شكله زي اللي في `.env.example`)

### 3. جهّز ملف `.env`
- انسخ `.env.example` وسمّيه `.env`
- حط رابط الاتصال اللي نسخته بدل القيمة الموجودة، وحط الباسورد بتاعك مكان `[YOUR-PASSWORD]`

### 4. ابني الجداول فعلياً على قاعدة البيانات
```
npx prisma db push
```
الأمر ده بياخد الـ schema من `prisma/schema.prisma` ويبني بيه الجداول على Supabase مباشرة.

### 5. زرع بيانات تجريبية (المنتجات والأقسام وحساب الأدمن)
```
npm run db:seed
```
ده هيعمل حساب أدمن جاهز (البيانات تحت في قسم "بيانات دخول الأدمن").

### ملحوظة عن `NEXTAUTH_SECRET`
لو مستخدم `setup.sh`، ده بيتولّد تلقائي. لو بتعمل الخطوات يدوي، ولّده بالأمر:
```
openssl rand -base64 32
```
وحطه في `.env` قدام `NEXTAUTH_SECRET`.

### 6. شغّل المشروع
```
npm run dev
```
دلوقتي الصفحة الرئيسية بتجيب المنتجات والأقسام من قاعدة البيانات فعلياً، مش من ملف وهمي.

### هتضيف منتجات جديدة إزاي؟
أسهل طريقة دلوقتي: `npx prisma studio` — بيفتحلك واجهة بسيطة في المتصفح تقدر تضيف وتعدل بيها البيانات من غير ما تكتب كود. لاحقاً هنعملك لوحة تحكم مخصصة أبسط من كده.

## إزاي تشغّل المشروع عندك

### 1. تأكد إن عندك Node.js
لازم يكون عندك Node.js نسخة 18 أو أحدث. تأكد بالأمر:
```
node -v
```
لو مش موجود، حمّله من nodejs.org

### 2. ثبّت المكتبات
افتح مجلد المشروع في الترمينال واكتب:
```
npm install --legacy-peer-deps
```
(الفلاج ده بيتجاهل تحذير نسخة `next-auth` مع Next.js 15، مش مشكلة حقيقية)

### 3. شغّل المشروع
```
npm run dev
```
بعدها افتح المتصفح على `http://localhost:3000`
